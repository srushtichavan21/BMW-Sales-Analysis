# BMW Sales Analysis (2010–2024)

## Project Overview
An end-to-end data analysis project exploring BMW sales data from 2010 to 2024 using Excel, MySQL, Python and Power BI.

## Tools Used
- **Excel:** Data cleaning, calculations and KPI analysis.
- **MySQL:** Data querying, aggregation, joins and business analysis.
- **Python:** Basic data exploration and analysis using Pandas.
- **Power BI:** Interactive dashboard and business insights.

## Key Analysis Areas
- Sales performance by year
- Model-wise sales comparison
- Regional sales distribution
- Fuel type analysis
- Transmission analysis
- Average vehicle price and mileage

## Key Findings
- Total sales volume: 253,375,734
- Number of BMW models: 11
- Regions analysed: 6
- Period covered: 2010–2024
- Hybrid recorded the highest sales volume among the fuel types.

## Project Structure
- **Excel** – Cleaned dataset and KPI analysis
- **SQL** – Queries and analysis
- **Python** – Jupyter Notebook
- **PowerBI** – Interactive dashboard

## Note
Estimated Sales Value is calculated using Price × Sales Volume. It is an analytical estimate and does not represent BMW's officially reported revenue or profit.
