BMW Sales Analysis – Power BI

This folder contains the interactive Power BI dashboard developed to analyse BMW sales data (2010–2024).

The dashboard includes three pages:
1. Executive Overview
2. Vehicle and Product Analysis
3. Sales Intelligence and Strategic Insights

It presents key performance indicators, regional sales distribution, model-wise performance, fuel type analysis, yearly trends and business recommendations.

Tool: Microsoft Power BI Desktop.

Note: Estimated Sales Value is calculated using Price × Sales Volume. It is an analytical estimate, not BMW's officially reported revenue or profit.
